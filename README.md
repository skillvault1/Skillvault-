# SkillVault V4 — Formspree Subscriber Notifications

The SkillVault newsletter form is connected to Formspree:

https://formspree.io/f/xeajrveg

Subscriber fields:
- Full name
- Email address
- Interest
- Automatic subject: New SkillVault Newsletter Subscriber

This uses Formspree's Vanilla JavaScript/AJAX integration, which is suitable for the static GitHub Pages website.

In your Formspree dashboard, configure notifications to the SkillVault admin email:
adminskillvault@gmail.com

Never put your Gmail password, Formspree password, API secret, or private token in the website files.
